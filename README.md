# Lovett — Artisan Botanicals & Natural Skincare Soaps

A modern, responsive e-commerce sales website for **Lovett**, handcrafted in Uganda. The design is themed in **safe botanical green**, **nourishing cream**, and **warm golden yellow**.

---

## 🌿 Product Collection

1. **Love it Aloe Vera Soap** — `5,000 UGX` per 100g
   * *Features:* Made of natural leaves. Good for everyday bathing routine, helps your skin feel comfortable and deeply moisturized.
   * *Best For:* Normal, dry, sensitive, and sun-exposed skin.

2. **Love it Turmeric Soap** — `7,000 UGX` per 100g
   * *Features:* Made with turmeric roots for brightening and toning skin. A revitalizing choice to add to your bathing routine.
   * *Best For:* Hyperpigmentation, dull skin, and evening skin tone.

3. **Love it African Black Soap** — `10,000 UGX` per 100g
   * *Features:* Made with traditional ingredients for cleansing, removes excess oils and deep dirt leaving the skin feeling fresh.
   * *Safety Note:* **Not good for dry skins.** Formulated specifically for oily and acne-prone skin.

## ✨ Features

- **Cart & Order System:** Slide-out drawer with quantity controls, subtotal, and promo code support (`LOVETT10` for 10% off).
- **Ugandan Delivery Calculation:** Destination selector covering Kampala Central, Greater Kampala/Wakiso, Entebbe, and Upcountry parcels, with free Kampala delivery unlocked at 35,000 UGX.
- **WhatsApp Direct Checkout & Consultation:** Instant ordering and 1-on-1 skincare consultations via WhatsApp (+256 761 506 828 / 0761506828).
- **MTN MoMo Merchant Payments:** Integrated payment support using MTN MoMo Merchant Code **41977046** (Dial `*165*3#`).
- **Native Checkout Dialog:** Support for MTN Mobile Money, Airtel Money, and Cash on Delivery.
- **Skin Routine Matcher Quiz:** Interactive tool to guide shoppers to the ideal soap based on skin type and skincare goals.
- **Quick View Modals:** In-depth ingredient profiles, usage directions, and safety cautions.
- **Mobile Responsive:** Optimized for both mobile devices and desktops.

## 🚀 Quick Start

No build tools or external installations required. Simply open `index.html` in any browser:

```bash
# Clone the repository
git clone https://github.com/naleeraalbright/Lovett.git

# Navigate to the folder
cd Lovett

# Open in browser (Windows PowerShell)
Start-Process index.html
```
